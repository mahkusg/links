# Mahkus — Links

Free static link-in-bio page for an X/Twitter bio.

## Edit your links

Open `index.html`, scroll to the `PROFILE` / `LINKS` config near the bottom, and swap in your real URLs. Redeploy by pushing to `main`.

## Live URL

After GitHub Pages is on: https://mahkusg.github.io/links/

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080
